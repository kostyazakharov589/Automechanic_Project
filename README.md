# 🚗АРМ автомеханика

**Автоматизированное рабочее место специалиста СТО** — это десктопное приложение для учета автомобилей, математического расчета износа деталей и предиктивного прогнозирования сроков ремонта. Проект включает аппаратную визуализацию на OpenGL и клиент-серверную архитектуру для отправки отчетов.
