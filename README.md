# 🚗АРМ автомеханика

**Автоматизированное рабочее место специалиста СТО** — это десктопное приложение для учета автомобилей, математического расчета износа деталей и предиктивного прогнозирования сроков ремонта. Проект включает аппаратную визуализацию на OpenGL и клиент-серверную архитектуру для отправки отчетов. Выполнил студент группы ИВТ-25-1б Захаров Константин.

**🌟 Ключевые возможности**

*  🔐 **Система авторизации:** Изоляция данных пользователей (у каждого механика своя локальная база клиентов). 

*  📊 **Интеллектуальный расчет износа:** Учитывает пробег, тип дорожного покрытия, сезоны года, "хронологическое старение" полимеров и каскадный износ (влияние сломанной подвески на другие узлы). 
*  🔮 **Предиктивная аналитика:** Программа высчитывает средний пробег пользователя и прогнозирует точную дату следующего визита на СТО.
*  🎨 **Интерактивная визуализация:** Векторная модель автомобиля, написанная на чистом OpenGL.
*  📑 **Экспорт и Отчеты:** Генерация текстовой диагностической карты с автоматическим созданием ссылок для покупки запчастей на **Avito** и **Drom**. 
*  ☁️ **Клиент-серверная синхронизация:** Отправка готовых отчетов по сети на локальный сервер руководителя. 
*  🗺️ **Интеграция с картами:** Поиск профильных автосервисов в Яндекс.Картах в один клик.
